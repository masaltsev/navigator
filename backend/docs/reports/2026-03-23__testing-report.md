### ⚠️ BK-01: PostGIS координаты
**Тесты:** Частично в `SafeImplementationTest::test_postgis_coordinates_are_returned()`
**Результат:** ⚠️ ТРЕБУЕТ УТОЧНЕНИЯ
- ✅ Координаты успешно извлекаются из PostGIS (проверено в tinker)
- ✅ Accessor `coordinates_array` работает корректно
- ⚠️ **Проблема**: Различие форматов list/detail view:
  - List view возвращает `venue` (singular) с координатами
  - Detail view должен возвращать `venues` (plural) с координатами
  - Тест ожидает detail view, но получает list view

**Решение:** Требуется уточнение логики в `OrganizationResource` или создание отдельных Resource классов для list/detail.

## 🔧 Исправленные проблемы

### 1. Фабрики моделей
**Проблема:** Поля `is_active` отсутствовали в базе
**Решение:** Удалены из всех фабрик:
- `ThematicCategoryFactory`
- `ServiceFactory` 
- `OrganizationTypeFactory`
- `SpecialistProfileFactory`
- `OwnershipTypeFactory`
- `EventCategoryFactory`

### 2. EventFactory
**Проблема:** Отсутствовал обязательный `organizer_id`
**Решение:** Добавлен `organizer_id` в определение фабрики

### 3. DictionaryController
**Проблема:** Фильтрация по несуществующему полю `is_active`
**Решение:** Убрана фильтрация, возвращаются все записи

### 4. OrganizationResource
**Проблема:** Сложная логика определения list/detail view
**Решение:** Упрощена логика, всегда возвращается `primary_phone`

### 5. OrganizationController
**Проблема:** В `show()` методе не загружался `organizer`
**Решение:** Добавлен eager loading `organizer`
